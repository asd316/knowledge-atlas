# 数据结构

所有内容都放在 `src/` 下的两个 JS 文件里，页面不需要构建就能直接读取。

## `src/data.js` → `window.ATLAS`

全局视图用的数据。

```js
window.ATLAS = {
  range: [1760, 2026],
  kinds:  { tech: {name, color}, cap: {...}, policy: {...}, idea: {...} }, // 连线类型
  eras:   [ ... ],                       // 历史分期，画成半透明平面
  shocks: [ {y: 1929, ...}, ... ],       // 大冲击，画成红色平面
  cats: [                                // 大类 → 小类 → 领域 id
    { id: 'tech', name: '技术与生产', color: '#38bdf8', subs: [
      { name: '信息技术', domains: ['elec', 'net', 'ai'] }, ...
    ]}, ...
  ],
  domains: {                             // 领域
    ai: { name, desc, pre /* 前史 */, stages: [[start, end, name, heat /* 1-3 */], ...] },
  },
  nodes: [ /* 节点 */ ],
  links: [ /* 跨领域连线 */ ]
};
```

### 节点

```js
{ d: 'media', y: 1833, w: 1, t: '便士报', x: '说明…', p: ['人物'], bk: ['书'], e: ['事件'] }
```

| 字段 | 含义 |
|------|------|
| `d` | 所属领域 id |
| `y` | 年份 |
| `w` | 重要度，取 1～3 |
| `t` | 标题 |
| `x` | 2～4 句说明，依次写背景、发生了什么、后果 |
| `p` | 关键人物 |
| `bk` | 关键书籍 |
| `e` | 关键事件 |

### 连线

```js
{ a: 'net', b: 'fin', y1: 1995, y2: 2000, k: 'cap', w: 2, t: '互联网泡沫',
  bg: '背景', what: '发生了什么', out: '后果', p: [], bk: [], e: [] }
```

| 字段 | 含义 |
|------|------|
| `a` | 起点领域 id，影响的源头 |
| `b` | 终点领域 id |
| `y1`、`y2` | 起止年份，分别对应光弧两端的高度 |
| `k` | 连线类型，取 `tech`、`cap`、`policy`、`idea` 之一 |
| `bg`、`what`、`out` | 分三段写的说明：背景、发生了什么、后果 |

`w`、`t`、`p`、`bk`、`e` 的含义与节点相同。

## `src/detail.js` → `window.ATLAS_DETAIL`

领域视图用的细节数据，按领域 id 分组。目前有 `ai`、`econ`、`money`、`psy` 四组。

```js
window.ATLAS_DETAIL = {
  ai: [
    { id: 'ai-p-turing', k: 'person', y: 1912, y2: 1954, w: 3, t: '艾伦·图灵', x: '…' },
    { id: 'ai-w-turing50', k: 'work', y: 1950, w: 3, t: '《计算机器与智能》', by: '图灵', x: '…', rel: ['ai-p-turing'] },
    { id: 'ai-d-symconn', k: 'debate', y: 1969, y2: 2012, w: 3, t: '符号主义 vs 连接主义',
      sides: ['甲方主张', '乙方主张'], x: '…', rel: [] },
  ]
};
```

### 字段

| 字段 | 含义 |
|------|------|
| `id` | 条目 id，格式为 `<领域前缀>-<类型字母>-<名字>`，例如 `ec-d-kh` 表示“凯恩斯 vs 哈耶克”这场辩论。领域前缀：`ai`、`ec`、`mo`、`ps`。类型字母：`p` 人物、`w` 著作、`i` 思想、`d` 辩论 |
| `k` | 条目类型，取 `work`（经典著作）、`person`（人物）、`idea`（思想）、`debate`（辩论）之一 |
| `y`、`y2` | 起止年份，含义见下表 |
| `w` | 重要度，取 1～3 |
| `t` | 标题 |
| `x` | 说明 |
| `by` | 作者或提出者，用于著作和思想 |
| `sides` | 辩论双方的主张，格式为 `[甲方, 乙方]` |
| `rel` | 同一领域内相关条目的 id 列表，在图里画成白色细线 |

### `y` 和 `y2` 的含义

| 类型 | `y` | `y2` |
|------|-----|------|
| 人物 | 出生年 | 去世年；在世者省略 |
| 辩论 | 开始年 | 结束年；仍在持续的省略 |
| 著作、思想 | 出版或提出的年份 | 不填 |

里程碑泳道没有单独的数据，内容直接取自 `ATLAS.nodes` 中属于该领域的节点。
