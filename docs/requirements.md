# 原始需求

本文记录项目的原始想法和需求访谈。用户原话一字不改，访谈问答只做了整理和摘要。

## 1. 最初的想法（用户原话）

> 我现在有一个想法：在学习很多领域的时候，我希望能把它们的前因后果和发展脉络串联到一块，这样就能看明白每个领域到底是怎么回事。
>
> 所以我需要一张图，大概是这样的结构：
> - 最底层：每个领域对应一根光柱
> - 上层：展示该领域存在的一些阶段性发展和关键节点
> - 中间层：不同领域之间跨越时间的相互交集与连线，每一条连线说明具体发生了什么事，才促成了领域之间的联动
>
> 我感兴趣的领域包括但不限于：设计、制造业、电子信息、AI、组织管理学、地缘政治、货币学、经济学、心理学，以及现代社会的商业架构。
>
> 在这个过程里，我非常渴望能看到它们之间的关联和一个宏观的大图景。另外，里面应该区分大类和小类，第一版希望能先把大框架搭出来，后续我们再逐步补充细分的小类。

## 2. 需求访谈

访谈采用 [interview-me](https://github.com/addyosmani/agent-skills/blob/main/skills/interview-me/SKILL.md) 的方式，一次只问一个问题。

| # | 问题 | 回答 |
|---|------|------|
| 1 | 这张图主要用来做什么？ | “主要是理清楚，所有知识的关联，看到关键点。因为很多知识，如果不建立全局，就很难继续学习” → 定位为**学习脚手架**，以看清全局为主，可以点开追问为辅 |
| 2 | 时间轴从哪里开始？ | **C**：从 1760 年工业革命开始，更早的历史只写一行“前史”；时间轴采用非线性刻度，越靠近现代越展开 |
| 3 | 用什么形式交付？ | **A**：可交互的网页 |
| 4 | 大类、小类指什么？ | **A**：大类是光柱的分组；AI 单独一根光柱 |
| 5 | 说明文字写到多深？ | **B**：一句话标题，加 2～4 句展开（背景、发生了什么、后果），再加“重要的人、书、事件” |
| 6 | 层级结构 | “整体应该是 3D 的，一个大类多个小类，小类里面有多个领域。” → **大类 → 小类 → 领域**；每个小类补满 2～3 个领域 |

## 3. 确认后的意图

- **用户**：本人，用于自学。
- **成功标准**
  - 打开页面，一眼能看出各领域的大脉络，以及它们在哪些年份交汇。
  - 每个节点和每条连线都有标题、2～4 句展开，以及关键人物、书籍、事件。
- **约束**：数据和页面分开存放，方便以后追加内容、拆分小类。
- **第一版不做**
  - 小类的进一步细分
  - 1760 年以前的详细时间线
  - 在页面里编辑内容
  - 打印版或海报版
  - 学术引用

## 4. 后续迭代中的用户反馈

1. **线框图评审**（`assets/wireframe.svg`）：
   > 风格基本对，但是也可以稍微变化点，你看下怎么能表示更多的信息。开始做吧
2. **领域视图（v2）**：
   > 看完全局后，是否能支持更细节的看一个领域内的变化，这个领域内的很多东西，比如 经典著作、辩论、人物、思想 随着时间线都可以提出来。然后也有和其他领域的，但是和其他领域的就没有必要展示另外领域的全部，可以点击跳转，但是默认还是在这个领域

   原话写的是“任务”，用户确认指的是“人物”。另外两项选择：
   - 领域视图采用 **3D 展开成泳道**。
   - **先做 3～4 个领域**，用户看过、觉得方向对了，再批量补齐其余领域。
